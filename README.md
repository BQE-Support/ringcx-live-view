# RingCX Live View

A read-only live queue and agent wallboard for BQE Software's RingCX contact center.

It is a static page with no server and no secrets. Each person signs in with their own BQE RingCentral account, and the page shows nothing until they do. It reads RingCX's real-time supervisor API directly from the browser.

Live at https://fred-bqe.github.io/ringcx-live-view/

This repo is published automatically from an internal source repo, so please don't edit it directly.
